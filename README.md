# Shibui
Normal note-taking apps fail with universal passive styluses—resting your palm causes ghost marks or kills touch response completely. SHIBUI fixes this with a bottom Bezel Zoom Pad so your palm rests off-screen while you write smoothly. Packed with 4 anime notebook styles, 0.5–5mm pens, an editable library, and smart 1-to-N offline PDF export!
